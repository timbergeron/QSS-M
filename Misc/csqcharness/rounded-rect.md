# Native rounded rectangles from QC

QSS-M exposes its existing rounded-fill renderer to CSQC and MenuQC:

```c
float(vector position, vector size, vector rgb, float alpha, float radius,
      optional float cornermask, optional float feather) drawroundedrect = #0;

if (checkbuiltin(drawroundedrect))
    drawroundedrect('16 16 0', '240 80 0', '0.04 0.06 0.08', 0.94, 10);
```

This is a QSS-M named extension. FTE's current `drawfill` takes position, size,
RGB, alpha and optional blend flags and has no rounded-rectangle builtin in its
CSQC/MenuQC tables. Keep `drawfill`'s established ABI and numbering unchanged;
use FTE's existing `#0` name mapping and `checkbuiltin` detection pattern for the
new operation. References checked on 2026-10-07:

- [FTE drawfill implementation](https://github.com/fte-team/fteqw/blob/master/engine/client/pr_menu.c)
- [FTE CSQC builtin table](https://github.com/fte-team/fteqw/blob/master/engine/client/pr_csqc.c)
- [FTE extension declarations](https://github.com/fte-team/fteqw/blob/master/quakec/menusys/fteextensions.qc)

Positions, sizes, radius and feather use virtual HUD/menu coordinates, including
fractional values. RGB and alpha remain floats and clamp to 0–1. A negative
radius selects one quarter of the shortest side; a large radius clamps to half
of that side. Zero radius draws a square rectangle.

Corner mask bits are top left = 1, top right = 2, bottom right = 4, bottom left =
8. An omitted or zero mask rounds all four corners. Feather defaults to one
physical pixel at the active CSQC/MenuQC scale; an explicit value is measured
in virtual units. Both optional arguments check the actual call argument count.

Returns 1 when drawn, or 0 for empty/negative sizes, transparent boxes, nonfinite
arguments, or invalid masks/feather. Drawing preserves the QC clipping region and
restores the blended texture state needed by subsequent pictures/text. The
existing shader's triangle-fan fallback remains available if shader creation is
unavailable. Engine menu callers retain their existing integer entry points.

`run_harness.py` covers registration and invalid input in both QC modules.
For screenshot assertions of radius clamping, corner masks, optional argument
defaults, alpha blending, clipping, textured drawing afterwards, and UI scaling:

```sh
python3 Misc/csqcharness/check_rounded.py \
  --bin /path/to/quakespasm --basedir /path/to/quake \
  --fteqcc /path/to/fteqcc --headers /path/to/csqcharness/src
```

The header directory must contain the CSQC/MenuQC platform dumps generated by
`run_harness.py` from the binary under test. The pixel runner uses temporary game
directories and checks CSQC and MenuQC at both scale 1 and scale 2.
