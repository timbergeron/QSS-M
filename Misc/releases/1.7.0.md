1.7.0 is the first release with the **built-in updater** (`update` command / Version menu). Future releases install from inside the game on Windows, Linux and macOS.

**Upgrading**
- Windows: 1.7.0 is a single static .exe. If you run a dev build from before October 28, 2026, its updater cannot install this release; download the zip below once and extract it over your install. Leftover DLLs from older builds are unused and can be deleted.
- macOS: the app is now signed with a Developer ID and notarized, so it opens without Gatekeeper workarounds. macOS treats it as a new app the first time, so it may ask once more for Input Monitoring (raw mouse) and Microphone (voice chat).

## Changes since 1.6.5

**Platform & updater**
- Migrated to SDL3, with smoother frame pacing, lower audio latency and better fullscreen recovery
- Self-updater for Windows, Linux and macOS
- Windows builds are statically linked: one .exe, no DLLs
- Quake data import workflow, plus Steam install detection on Windows
- macOS: HID raw mouse input, Dock menu, Dock badges and download ring, hold-Cmd-Q to quit, App Translocation fix, minimum macOS is now 12.0
- Windows: taskbar download progress and notification badges
- Startup and shutdown are faster (lazy asset loading, background requests cancelled on quit)
- Map loading is faster: parallel texture preparation, partial lightmap uploads, fewer hunk copies, cached pak sounds
- `games/`, `mods/`, `paks/` and `configs/` subfolders; config.cfg now lives in `configs/`

**Menus & UI**
- Unified menu search / command palette (Ctrl/Cmd-K) with fuzzy matching and synonyms
- New menus: mod downloader, map downloads, mods with descriptions, sound/music browser, model viewer, skybox viewer, keyboard shortcuts, Discord, network, version, controller, weapon wheel order, name history, color picker
- Mapshots in menus, on loading screens and in Discord
- Server browser: asynchronous public server list, sorting, search, pinned bookmarks, player and score hover, port ping probes, dated server history
- Settings apply live, with live previews (`ui_live_preview`), live MSAA and live texture refresh
- Mouse support across classic menus, text selection in menus, startup and quit fades

**Console & chat**
- Console text selection and copy, clickable links and paths, undo/redo, word completion, typo suggestions
- Many more tab completions for commands, cvars, files, names and quoted arguments
- Chat input cursor editing, selection and sent-message recall
- Player chat translation
- Typing and AFK status above players (`con_typing`)
- `ignore` / `unignore`, name history (`namehistory`), `cmdcycle`, FTE-style `cvarlist` filters

**Multiplayer & networking**
- Asynchronous, non-blocking server connects and domain lookups
- Faster FTE-style chunked downloads, asynchronous skybox and web downloads
- Netgraph diagnostics panel, `netdrops`, `netfps_probe`, scoreboard packet loss
- Hitscan lag compensation (anti-lag) and better prediction feedback
- Discord rich presence, notifications and optional server-switch announcements
- CRMod 7 command menu, Head Hunters and Clan Arena HUD support, match clock count-up, wipeout countdown
- Scoreboard scrolls for up to 255 players
- Server-side: `sv_modvote`, `sv_mapcrc`, `sv_settimer`, packet-loss detection, fifo console commands, ICE/WebRTC server support
- Hardened against malformed server messages, demos and downloads; rcon credentials and private configs are protected from gamecode and remote commands

**Demos**
- Instant FTE-style seeking, `jumpdemo`, `markdemo`, mouse scrubbing on the demo bar, J/L 10-second skip
- `cl_demo_eyecam` (chasecam demos as eyecam), `cl_demoeyes`, `r_player_xray` for observers
- Demo menu: subfolders, search across maps, descriptions and metadata, preview tooltips, `cl_demo_minframes` to hide short demos
- Asynchronous demo recording and dzip compression; dzip playback support

**Rendering**
- Powerup shells with soft glow (`gl_powerupshells 2`), pulsing grenade glow, model outlines for brush pickups and IQM
- `r_grass` animated grass with travelling wind gusts
- FTE teleporter refraction and reflection (`r_telestyle`)
- Ironwail software-style underwater warp and basic software emulation mode
- Water fog, global fog (`r_fogalpha`), fog dithering, FXAA, motion blur (`gl_motion_blur`), radial vignette (`gl_polyblend 2`)
- Weapon wheel, `cl_gunx/y/z` viewmodel offsets, `v_viewheight`, `cl_gun_drift`, `cl_maxroll`, smoother stairs and elevators
- Particle, shadow, translucency, lightmap and brush-model batching and caching: higher fps on large maps
- Collision hull and entity debug views (`r_showhull`, `r_showfields`)

**Single player & mods**
- Quake Enhanced: rerelease saves, rotating brush models, weapon preferences, candlelight, weapon wheel, localization (Q30 update)
- MG3, Arcane Dimensions, Copper and jam pack compatibility fixes, clientside candles
- `massacre`, `resurrect`, coop `goto`, improved `give`, `r_ambient`, `showflags`
- Much broader CSQC and MenuQC builtin coverage, with FTE numbering parity

**Ported from Ironwail** (thanks, Andrei Drexler): controller support (gyro, rumble, flick stick, hot-plug), dynamic hunk allocation, threaded background saves, bindlist, map ordering and more. See the README for the full list.
