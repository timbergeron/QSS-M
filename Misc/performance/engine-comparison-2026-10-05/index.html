How QSS-M's map loading got faster

A nine-round head-to-head against the two engines that led loading before this work, with the original QSS-M build as the baseline. Endpoint for every engine: completed client signon after the map command.

Each change was kept only after its own back-to-back A/B. The figures are that A/B's medians, measured in different sessions, so they don't add up exactly to the totals above.

    Nine maps and two real games

    Native timedemos in a fresh process per pass: one discarded warm-up, then five measured passes per engine, 800 × 600, uncapped, VSync and MSAA off. The nine-map suite plays the same recorded 360° turn at each map's first deathmatch spawn. Two gameplay demos add real movement and combat: a 16-player CTF match and Sphere's 2:14 ad_tears speedrun.
