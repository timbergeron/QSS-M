Windows/build-static.py. The following describes the retained legacy DLLs.

The public mikmod.h comes from the same package.

x86: built from that upstream source with MinGW-w64 GCC 13 (win32 threads).
MSYS2 no longer publishes libmikmod for mingw32. From the repository root,
set mikmod_source and mikmod_build to absolute paths for the extracted source
and scratch build:

mkdir -p "$mikmod_build"
cd "$mikmod_build"
"$mikmod_source/configure" --host=i686-w64-mingw32 \
  --enable-shared --disable-static --disable-sdl \
  --disable-xaudio2 --disable-openal \
  'LDFLAGS=-static-libgcc -Wl,--no-insert-timestamp'
make -j4
i686-w64-mingw32-strip --strip-unneeded .libs/libmikmod-3.dll

Copy .libs/libmikmod-3.dll into Windows/codecs/x86/. Both architectures include
DirectSound, WinMM and WASAPI output drivers, but QSS-M registers only drv_nos
and decodes through VC_WriteBytes. All previous exports remain available;
imports are limited to Windows system DLLs, including msvcrt.dll. No shared
GCC, winpthread, UCRT, or other new runtime DLL is required.
